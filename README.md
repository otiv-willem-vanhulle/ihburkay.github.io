# Ibrahim Burkay's CV Website

This repository contains the source code for Ibrahim Burkay's CV website. The website is designed to showcase the skills and experience of Ibrahim Burkay, a Turkish backend developer, and make him attractive for companies to recruit.

## How to View the CV

To view the CV, simply open the `index.html` file in a web browser. The CV content will be dynamically loaded and styled using the linked CSS and JavaScript files.

## How to Edit the CV

To edit the CV, follow these steps:

1. Open the `index.html` file and locate the section with the ID `cv-content`.
2. Modify the HTML content within this section to update the CV information.
3. Save the changes and refresh the web browser to see the updated CV.

## Files in this Repository

- `index.html`: The main HTML file for the CV website.
- `styles.css`: The CSS file for styling the CV sections, header, and footer.
- `script.js`: The JavaScript file for handling interactivity and dynamically loading CV content.
